## 2026-11-25: Lost art masters, and recording README media in a cloud session

- **A "lost" Codex image is usually still on the Mac.** Codex keeps every generated image under `~/.codex/generated_images/<session>/`. The `random-choice.png` master, logged as never archived, was found there by its manifest sha256 and uploaded to `legatum-art-sources`. Search there by hash before regenerating a master.
- **README loops can be recorded in a cloud session.** `docs/media/src/refresh.sh` runs headless. The only snag is the browser: when the container's Playwright browser build differs from the one the app's Playwright expects, every clip fails with "Executable doesn't exist". Point a throwaway config at the pre-installed Chromium (`use.launchOptions.executablePath`, spread over `playwright.media.config.ts`), then record one clip with `MEDIA_ONLY=<clip>`.
- **Crop a loop at 16:9; don't pad it.** `loop-factions` used to crop only the faction sheet (about 3:2), then pad it with parchment to 16:9, which cut off the sheet's last lines. Cropping the whole picker dialog at 16:9 (`1648:927:136:75` in the 1920x1080 master) shows the list being clicked as well as the sheet, and needs no padding.
