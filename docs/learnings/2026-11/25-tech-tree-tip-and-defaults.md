# Tech tree view: two things that cost time (2026-11-25)

- **`Tip` inside a `<button>` swallows the button's click.** `Tip` (app/src/ui/Tip.tsx) treats a click on a trigger with no control inside it as "pin the tooltip" and stops propagation, so a Tip wrapping the unlock pictures inside a tree node ate the node's Shift+click. `Tip` only passes clicks through when the control is *inside* it. Put a Tip around a control, never inside one; the tree nodes use the native title and an aria-label instead.
- **Changing a screen's default view breaks every spec written for the old one.** Research now opens on the tree, and about 30 e2e specs and two unit test files click the era cards. Rather than edit each, the shared e2e fixture's init script (`skipPeopleIntro` in e2e/fixtures.ts) sets `legatum.research-view.v1` to `era` when unset, the unit tests set it in `beforeEach`, and `e2e/research-tree.spec.ts` removes it to test the real default. The research dialog's first Tab stop is now the view switch, not Close.
