# A Playwright bump leaves the art tools without a browser (2026-11-25)

Each Playwright release pins one Chromium build (1.65 wants chromium-1255). After the npm group bump (#61), the Mac and the cloud containers still had only the older build (1243), so `tools/art/render-sets.mjs`, and through it `artDistinct.test.ts` and `tools/gates/art.py`, failed locally while hosted CI (which downloads the browser) passed. `tools/art/launch-chromium.mjs` now tries `LEGATUM_CHROMIUM` (an executable path), then Playwright's default, then the newest `chromium-*` already in a Playwright browser folder (`PLAYWRIGHT_BROWSERS_PATH`, `/opt/pw-browsers`, `~/.cache/ms-playwright`, `~/Library/Caches/ms-playwright`). Rendering with a slightly older Chromium is fine for these canvas draws. The e2e suite still needs the pinned build or a `PLAYWRIGHT_BROWSERS_PATH` folder of symlinks.
