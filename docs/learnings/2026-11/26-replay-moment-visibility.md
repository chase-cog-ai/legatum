# Replay labels use contact at the time of the event

The replay sidebar is visible before jumping to a turning point. Redact unmet actors from each milestone using the viewer's fogged state immediately after that event's turn, not the frame currently on screen or the finished report. As in the live report, the viewer's own empire and its declared enemies are named. The replay VP badge shows only the viewer's score from the current recorded frame.

The replay still paints that frame through the shared 2D renderer, using one bounded terrain cache per mounted replay rather than the live map's cache.
